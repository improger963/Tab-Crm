# Ուղեցույց. Ինչպես աշխատեցնել նախագիծը համակարգչում Git-ի միջոցով

Այս ուղեցույցը քայլ առ քայլ բացատրում է, թե ինչպես քլոնավորել և տեղային (localhost) գործարկել նախագիծը ձեր համակարգչում։

---

## 1. Նախապայմաններ

Համոզվեք, որ ձեր համակարգչում տեղադրված են՝
- **Git** — [Ներբեռնել Git](https://git-scm.com/)
- **Node.js** (v18 կամ ավելի բարձր, առաջարկվում է v20+) — [Ներբեռնել Node.js](https://nodejs.org/)

---

## 2. Քլոնավորել նախագիծը (Git Clone)

Բացեք տերմինալը (Terminal / Command Prompt / Git Bash) և կատարեք հետևյալ քայլերը՝

```bash
# Քլոնավորեք ռեպոզիտորիան
git clone <ՁԵՐ_ՌԵՊՈՅԻ_URL-Ը>

# Մտեք նախագծի թղթապանակ
cd <թղթապանակի_անունը>
```

> **Նշում:** Եթե նախագիծը դեռ Google AI Studio-ում է, վերևի մենյուից ընտրեք **Export to GitHub** կամ ներբեռնեք ZIP արխիվը։

---

## 3. Տեղադրել անհրաժեշտ փաթեթները (Dependencies)

Տերմինալում աշխատեցրեք՝

```bash
npm install
```

*(Կարող եք օգտագործել նաև `bun install`, եթե նախընտրում եք Bun)*

---

## 4. Կարգավորումներ

Նախագիծն աշխատում է ամբողջությամբ օֆլայն և չի պահանջում API բանալիներ կամ `.env` կարգավորումներ։ Բոլոր տվյալները պահպանվում են դիտարկչի `localStorage`-ում, իսկ արտադրանքի JSON բեքափերը կատարվում են հավելվածի ներսից (JSON Database էջ)։

---

## 5. Գործարկել նախագիծը (Development Mode)

Նախագիծը գործարկելու համար աշխատեցրեք՝

```bash
npm run dev
```

Գործարկվելուց հետո բրաուզերով անցեք հետևյալ հասցեով՝
👉 **http://localhost:3000**

---

## 6. Օգտակար հրամաններ

- **Կոդի ստուգում (Lint / Typecheck):**
  ```bash
  npm run lint
  ```

- **Արտադրական տարբերակի կառուցում (Build):**
  ```bash
  npm run build
  ```

- **Build-ի նախադիտում (Preview):**
  ```bash
  npm run preview
  ```

- **Վերջին փոփոխությունները GitHub-ից քաշել (Pull):**
  ```bash
  git pull origin main
  ```
